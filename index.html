FAQ

Frequently Asked Questions

Everything you need to know about MR Print Hub before downloading.

Does MR Print Hub require an internet connection? ▾
No. MR Print Hub works entirely over your local Wi-Fi network. Files transfer directly between your customer's phone and your Windows PC using your shop's Wi-Fi router. No internet connection is needed at any point. This also means file transfers are faster since they use LAN speed instead of internet bandwidth.
Do customers need to install an app on their phone? ▾
No. Customers simply scan the QR code displayed at your shop counter using their phone's built-in camera. This opens a browser-based upload page at mrprinthub.local/quickupload. They can select and upload files directly from their phone browser — no app download, no account creation, no sign-up required.
What file types can customers upload? ▾
MR Print Hub supports PDF documents, image files (JPG, PNG, and other common formats), and DOCX (Microsoft Word) files. All uploaded files go through extension validation to ensure only supported file types are accepted by the system.
How are the files secured? ▾
MR Print Hub uses multiple layers of security. Every upload session is protected by CSPRNG (Cryptographically Secure Pseudo-Random Number Generator) tokens, so each QR code generates a unique session that cannot be guessed. Files go through a background service pipeline that includes antivirus scanning and extension validation. Built-in firewall protection prevents unauthorized access. All files are stored locally on your PC at ProgramData/MRPrintHub/Uploads and never leave your network.
Where are the uploaded files stored? ▾
All files are stored locally on your Windows PC at ProgramData/MRPrintHub/Uploads. You can manage your storage through the built-in Storage Manager accessible from the sidebar navigation. No files are ever sent to cloud storage or external servers.
Can multiple customers upload files at the same time? ▾
Yes. MR Print Hub handles multiple simultaneous uploads. Each customer gets their own secure session with a unique CSPRNG token. Files from different customers appear in your Live Upload Stream in real time, each with its own verification status bar so you can track every submission individually.
What operating systems does MR Print Hub support? ▾
MR Print Hub is a Windows desktop application that runs on Windows 10 and Windows 11 (x64 architecture). It requires 4 GB of RAM and a local Wi-Fi network. The customer-facing upload page works on any phone with a modern web browser — both Android and iOS are supported since it is browser-based.
How does the QR code system work? ▾
MR Print Hub generates a Live QR code that encodes your shop computer's LAN IP address and a secure session token. You can display this QR code on your screen or print it as a QR ticket using the "Print QR Ticket" button. When a customer scans it, their phone connects to your local Wi-Fi network and opens the upload page. Each session has an expiry timer for added security.
Is MR Print Hub free to use? ▾
Yes. MR Print Hub v1.0.0 is available as a free download. There are no subscription fees, no usage limits, and no hidden costs. The software runs entirely on your own hardware with no external dependencies or SaaS requirements.
